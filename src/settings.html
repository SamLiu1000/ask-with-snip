API Key 只保存在你本机的配置文件里，不会上传到任何第三方（除了你自己填的服务商）。

勾选：新截的图会接到当前这段对话后面，前面看过的图仍在上下文里，适合"截一段问一句、再截一段接着问"（读长文档、翻长代码）。注意每轮的图都会随请求一起发出去，攒得越长越贵。这条也能在问答窗口里临时切换。
